# Media Studio v1 — 使用与验收

新版后台位于 `/studio/`，和原 `admin.html` / `admin-imgtc.html` 并存。

## 部署方式

正式版已发布：**https://my-image-bed.pages.dev/studio/**，使用原正式后台账号登录。正式站固定发布版本，后续开发走独立 Preview，Draft PR 未合并。下方早期预览说明仅为历史参考。
开发继续在草稿 PR 中进行；正式站使用独立固定发布分支。

只有 PR 合并或手动发布到 Production 后，`https://my-image-bed.pages.dev/studio/` 才应成为正式访问路径。

## 登录
使用 Cloudflare Pages Production/Preview 对应的 `BASIC_USER`、`BASIC_PASS`。新版后台的登录凭据只保存在网页运行内存，页面刷新后会消失。请务必为预览环境也绑定 `img_url` KV，否则预览数据不会完整。

## 现有功能（相册管理更新版）
- 分页加载记录，按文件名、标签、旧版相册标签、分类和排序
- **多级虚拟相册**：创建、重命名、调整父级、删除空相册；左侧目录树及窄屏下拉切换
- 左侧采用真正的可展开/折叠文件夹树：箭头控制展开，文件夹名称负责打开，展开状态在页面会话内保留
- **C 混合模式**：打开父文件夹默认只显示直接归属的素材，并显示其直接子文件夹卡片；勾选「包含子文件夹素材」才汇总所有下级媒体
- 可点击面包屑路径逐级返回父文件夹，移动或创建子文件夹后自动展开所属父级；窄屏使用文件夹下拉切换；可查看未归类素材
- 选择素材后可批量移入文件夹或移回未归类状态（一次最多 50 个）；图片原 URL 永远不变
- 预览图片、视频，复制图片真实链接
- 当前筛选结果全选，以及顺序遍历剩余 KV 页面后跨页选中（最多自动遍历 100 页）
- 批量收藏/取消收藏、添加/移除标签、添加/移除相册、设置分类
- 批量发布给 AI / 撤销发布；操作分批最多 50 条并反馈进度与失败项目
- 基于现有 `/upload` 端点批量上传并刷新页面；新上传默认不收藏、不发布

## D1 数据库（Preview 已启用）

预览环境使用独立的 Cloudflare D1 数据库 `media-studio-preview`（Pages Functions binding: `MEDIA_STUDIO_DB`）。
**Preview 与 Production 已分别使用独立 D1，不得混用。Production 数据库为 media-studio-production-20261117。**
在配置了 D1 的环境中，相册列表/创建/更名/移动/删除及素材的文件夹归属以 D1 为唯一真值来源；
`img_url` KV 保留原文件记录与存储/审核信息；可编辑资料在已启用 D1 的环境以 D1 为准。
缺少 D1 绑定的环境保留旧 KV 相册逻辑用于兼容，但这并不代表正式站点已完成迁移。

- 版本化 D1 结构：`migrations/0001_media_studio_folders_d1.sql`
- 主要数据表：`studio_folders` 与 `studio_media_folders`；后者引用前者并阻止非空删除
- Preview 初次迁移已复制原有 2 个相册、2 条图片归属关系；没有删除任何 KV 图片
- 使用 D1 主数据库进行写后查询，避免 KV 的最终一致性导致相册创建/删除后反复刷新
- 前端将 D1 列表视为权威结果，不使用原有 KV 写后短期覆盖机制
- 最新正式版和 Preview 的标签、收藏及 AI 发布状态已分别迁入独立 D1。

## 数据规则
- `liked`：个人收藏（**不自动公开到 AI 目录**）
- `aiPublished`：人工明确授权 AI 目录列出该图片
- `tags`：字符串数组，逻辑标签
- `albums`：旧版字符串数组标签式相册（兼容保留；可多选）
- `folderId`：新版单一虚拟文件夹 ID。在配置了 D1 的预览版中来自 `studio_media_folders`；未绑定 D1 的旧环境仍可读取 `studio:folder:<id>` KV 记录
- 新版相册支持树状父子关系，同一张媒体通过标签仍可在多个筛选条件中出现
- `category`：单一分类字符串
- 黑名单和 NSFW 项目不会出现在 AI 目录
- AI 目录目前只索引图片，不索引视频

## 重要安全提示
- 现有公开图片 URL 仍可能被任何知道 URL 的人访问，`liked` 或相册并不提供私密存储权限。
- `/studio/` 是静态登录页面，不返回后台数据；后端 API 必须通过 Cloudflare 后台 HTTP Basic 认证。
- `/upload` 使用项目原有配置。若先前为了修复 401 而移除了 `UPLOAD_BASIC_USER/PASS`，上传接口**仍然是公开的**；此 PR 没有修复上传授权。
- 预览环境的数据和生产环境 KV 绑定可能不同，请确认后再批量操作。

## 验收检查
1. 使用预览地址 `/studio/` 登录，看见现有素材
2. 勾选多个媒体，并执行批量收藏，检查每个收藏状态
3. 跨页加载后仍保留选中状态，测试“选择全部匹配结果”
4. 创建「工作项目」及其子相册「Shopify 店铺 A」，选择多张素材批量移入子相册，立即刷新验证 D1 持久化与父子关系
5. 重命名相册、修改父级，然后尝试删除非空相册，验证删除被拒绝
6. 给一张图片收藏但不发布 AI，公开目录不得出现该图片
7. 选择另一张图片发布 AI，确认目录返回且图片 URL 可以访问
8. 撤销发布后，公开目录应不再列出该图片
9. 验证旧 `/admin-imgtc.html`、上传页和已有 `/file/<id>` 链接没有受影响

## Reliability update (2026-11-17)

- D1 migration `0002_media_studio_folder_guards.sql` protects directory structure at write time, including concurrent moves. It is currently applied only to the isolated Preview database.
- Batch completion keeps only unsuccessful/unconfirmed items selected. On interruption, completed successes are excluded from the retry selection; failed and unsent items remain selected. A timed-out request may already have succeeded; repeat the same action to retry safely.
- Run `npm test` for unit and local Miniflare D1 SQL integration tests. This does not replace authenticated browser acceptance.


## 标签管理（2026-11-17）

选择素材后点击「＋ 标签」或「－ 标签」打开标签面板，可搜索并勾选已有标签；添加时可输入新标签，支持中英文逗号或换行分隔。移除只作用于所选素材，不会全局删除标签。

筛选栏新增「全部标签」下拉框，按完整标签精确匹配，并可与文件夹、搜索、媒体类型组合。标签列表来自已加载素材；如需查看全部标签，请先加载剩余页面。

每次最多处理 15 个标签，每个标签最多 48 字，每张素材最多 30 个。超限保留原数据并提示失败；失败项保持选中。标签操作不会改变收藏或 AI 发布状态。


## 可编辑素材详情（2026-11-17）

相册归属通过「应用相册」单独保存，收藏、AI 发布也各自独立。发布 AI 需要明确确认。保存失败保留输入，保存期间禁止重复操作。所有编辑保持原始文件和 `/file/<id>` 链接不变。

## 上传通道更新

Studio 使用已登录的后台账号，通过独立的管理上传接口上传，不再依赖匿名 /upload，也不需要在前端保存另一套上传密码。新素材默认位于未归类，不自动收藏或公开给 AI。

管理上传默认每文件 50 MiB，可用 STUDIO_MAX_UPLOAD_BYTES 设置限制；支持常见图片和视频扩展名，不支持 SVG。大小与扩展名检查不等于内容审核。上传失败会保留反馈；新上传记录不会因立即刷新列表尚未读到 KV 而在当前会话消失。

远程 Preview 仍按设计禁用上传；本轮使用本地隔离存储验证，没有复制 Telegram 凭据。生产 /upload 鉴权尚未启用，迁移与上线需另行批准，详见 docs/PRODUCTION_READINESS.md。


## 全库检索（2026-11-17）

登录后，在「全选当前结果」旁点击「全库检索」。该入口仅在 D1 元数据模式开启且索引初始化完成后启用；主页面原搜索仍筛选已加载素材。

支持关键词（文件 ID、显示名称、标签、分类、旧版相册标签）、精确标签、旧版相册标签、素材类型、收藏、AI 发布、文件夹与显式包含子级，以及时间/名称排序。检索由服务端执行，每次加载 50 项，无须先遍历 KV 页面。标签建议来自全库，最多显示 500 个，仍可手动输入精确标签。

点击结果可编辑详情；已保存的 D1 修改会立即用于下一次检索。保存后请重新检索以更新匹配结果和数量。跨页勾选保留，点击「用于批量操作」返回主界面使用现有批量工具；选择数量包含此前已选素材。

索引表 studio_media_inventory 仅保存派生的媒体清单和白名单元数据，原始文件仍在 Telegram/原存储，原记录仍在 KV。版本化编辑和删除标记继续以 studio_media_metadata 为准，不由旧 KV 覆盖。新版本上传成功写入 KV 后会同步索引；旧部署和外部直接写 KV 不会自动补录，需要重新核对索引覆盖。

初始化顺序：应用 migrations/0004_media_studio_catalog.sql（默认 ready=0），分页读取目标环境 KV 的媒体键与元数据，用 functions/utils/studio-catalog.js 的白名单规范导入清单；核对媒体键覆盖、原编辑版本及外键后才将 studio_catalog_state 的 ready 设为 1。不得导入 KV 原始值或把 Preview 库用于 Production。失败时保持 ready=0。

游标绑定本次筛选条件；修改表单后需重新提交。分页期间若有并发编辑，结果不是整场检索的固定快照。名称/关键词大小写比较采用 SQLite 的默认规则，不保证任意 Unicode 的大小写折叠。


## 全局标签管理（2026-11-17）

「标签管理」入口位于「全库检索」旁，需全库索引就绪。面板按全库在用标签展示素材数量，支持搜索、每页 100 个标签及载入更多。点击「查看素材」可打开该标签的全库结果。

选择标签的「管理」后，可重命名为全库尚不存在的新标签，或明确选择「合并到已有标签」。合并会移除重复标签并保留其他标签的相对顺序。两种操作均作用于整个索引库中的匹配素材，不限于已加载或已选素材。提交前需勾选范围确认；修改目标或操作方式会取消勾选。

成功后刷新素材列表并清空当前选择，以读取最新版本；失败保留输入，并刷新统计供核对。操作超时也可能已完成，请先核对标签统计再重试。其他窗口打开的旧详情保存会遇到版本冲突，需要重新载入资料。

标签名称最多 48 字，重命名与合并区分大小写。没有使用的标签自动不再出现，不存在独立的空标签记录。本轮未增加全局标签删除按钮。原始文件、链接、收藏、AI 发布状态和相册归属不因标签整理而改变。


## 下载与导出（2026-11-17）

素材详情新增「下载 / 导出」，可保存单个原文件。选中素材后，批量工具栏中的同名按钮可生成 ZIP，或导出 JSON / CSV 资料。任务使用打开面板时的选中项，不因随后选择变化而改变，也不清空原选择。

ZIP 使用不压缩打包，文件名带序号防止同名覆盖，并保留原文件扩展名。每批最多 100 个文件，每文件最多 50 MiB，原始内容合计最多 100 MiB；单文件下载使用相同的 50 MiB 限制。资料导出最多 1000 项，服务端每次读取 50 项。资料包括显示名称、原始公开链接、类型、大小、时间、标签、旧版相册、当前相册路径、分类、收藏和 AI 发布状态，不导出 KV 原始值、Provider 内部引用或认证信息。

下载时展示进度，可取消。任何一项缺失、受限制、读取失败或超出容量时，整次任务停止，不生成缺少文件的 ZIP；错误和当前选择保留以供重试。成功提示表示已交给浏览器下载，请在下载列表确认最终保存。已删除记录不导出，下载遵守当前黑名单及白名单模式。

CSV 含 UTF-8 BOM，数组保存为 JSON 文本，表格公式前缀会加单引号，减少导入电子表格时的公式执行风险。JSON / CSV 读取各批次的最新资料，不保证跨批次并发编辑时的全库固定快照。导出中包含公开素材链接，请按自己的分享范围保管文件。

Preview 下载通过固定的正式站公开文件路径取得内容，不复制 Telegram 凭据；本轮浏览器验收使用本地隔离 R2 样例。超过当前浏览器容量的超大文件和大规模后台归档任务留待后续版本。


## 索引维护（2026-11-17）

已初始化全库索引的环境，在「索引维护」中可检查并补齐漏录素材。新版本上传仍会直接加入索引；旧部署或外部程序直接写 KV 后，可在此手动启动整库扫描，随后自动逐页处理。

面板显示索引条数、可检索条数、删除标记数，以及 D1 资料/相册归属缺少对应索引的数量。扫描每页最多 100 个 KV 键，补齐或刷新白名单索引字段；内容未变化则不重复写入。整页成功后才推进检查点，失败或暂停可从上次确认位置继续；每次运行最多 1000 页，可继续下一轮。

检查点只含游标和进度，不保存账号密码，保存在当前标签页的 sessionStorage；刷新并重新登录后可继续。同一标签页访问的 Preview 域名变化、浏览器存储被禁用或游标失效时，可能需要从头检查。旧游标失效不会自动跳过该页。

补录不会覆盖 D1 中的标签、名称、收藏、AI 发布、版本和删除标记，也不改相册归属、KV 原始记录或 Telegram 文件。因 KV 最终一致性或并发写入，本次扫描不代表某一时刻的完整快照；未在本次列表出现的旧索引不会自动删除。缺少源元数据或整页写入失败时停止并提示重试。关系异常只报告数量，需人工核对来源。

这是手动启动的维护工具，没有配置定时后台任务，也不能代替首次迁移初始化。扫描完成后，全库检索可以立即查询补齐素材，普通主列表按原方式刷新/加载。


## 素材描述、来源与 AI 提示词（2026-11-17）

在索引就绪、D1 元数据模式开启的环境，素材详情新增「素材资料」：描述（最多 4000 字）、来源链接（最多 2048 字）与 AI 提示词（最多 8000 字）。描述和提示词保留多行原文，支持复制提示词；来源仅接受无内嵌账号密码的 HTTP(S) 地址，不自动抓取网页。

修改后点击「保存资料」，可清空字段。它们与名称、分类、标签一起受详情版本检查保护；保存失败/冲突保留草稿，收藏或移动等独立操作不会清空输入。旧客户端未提交这些字段时保留原值。未启用 D1 的环境拒绝保存新增字段，避免超过旧 KV 元数据容量。

主界面已加载素材搜索和全库关键词检索均包含描述、来源链接及提示词。后台 JSON / CSV 导出包含这三项；CSV 在原 14 列后追加 description、sourceUrl、prompt，共 17 列。

这些资料只通过已认证的后台接口读取。即使素材已发布 AI，公开 /api/shopify-assets 仍不包含描述、来源或提示词；发布/撤销规则保持原样。保存不会调用 AI 服务或产生模型费用。本轮不包含自动识图、自动生成提示词或外部 AI 模型集成。导出文件可能含个人笔记和提示词，请按自己的分享范围保管。
