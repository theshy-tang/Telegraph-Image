# 上传时导入标签

把素材与一份 UTF-8 编码的 `media-tags.json` 同时拖到「上传素材」，也可以点击后一次选中这些文件。清单格式如下。

```json
{
  "version": 1,
  "items": [
    { "fileName": "湖畔帐篷.png", "tags": ["户外", "帐篷", "暮色", "横幅候选"] },
    { "fileName": "营地短片.mp4", "tags": ["露营", "夜景"] }
  ]
}
```

`fileName` 填写素材的原文件名，含扩展名，匹配区分大小写。清单最多 1 MiB，每项最多 30 个非空标签，每个最多 48 字。上传前可逐项核对标签。遇到未匹配、同名或无效标签时，可取消并修正清单，也可确认让对应素材以无标签状态上传。清单文件仅在浏览器读取。

标签随素材登记一起保存，上传后可在素材详情里查看和编辑，也可通过标签筛选。图片尺寸仍由系统读取，AI 发布仍需在后台单独操作。
